# AssemblyVision

AssemblyVision is an edge-first industrial assembly inspection platform for conveyor-based production lines. It uses two-stage object detection, deterministic product rules, local durable storage, and delayed synchronization to a central management system.

The repository currently contains the implementation-oriented architecture baseline. It does not yet contain a production implementation or validated performance claims.

## Bilingual Documentation Site

The repository ships a bilingual (English + Chinese) MkDocs site with automatic translation,
adapted from the `crud-skeleton` project. `docs/` is the English source of truth; the Chinese
mirror `docs-zh/` is generated by machine translation. All content is translated, including the
architecture design set, the research reports, and Mermaid diagram labels (diagram syntax is
preserved).

```bash
pip install mkdocs-material deep-translator
bash scripts/build-docs.sh   # translate -> build site/ (EN) and site/zh/ (ZH)
```

- `mkdocs.yml` — master configuration (single source of truth, includes Mermaid rendering)
- `scripts/translate-docs.py` — mirrors `docs/` to `docs-zh/` (free `deep-translator`, no API key)
- `scripts/generate-mkdocs-configs.py` — generates `mkdocs-en.yml` and `mkdocs-zh.yml` from the master
- `.github/workflows/docs.yml` — auto-builds and deploys to GitHub Pages on push to `main`

`docs-zh/`, `site/`, and the generated configs are build artifacts and are not committed.
Machine translation is a starting point and should be reviewed before external publication.

## Safety Position

AssemblyVision prioritizes high NG recall and an extremely low false-negative rate. Only complete, valid evidence for every required component may produce `OK`; missing, uncertain, or unverifiable evidence produces the business result `NG`. Production acceptance must use measured customer production data excluded from training.

## Delivery Horizons

- **Two-day MVP:** static images, two-stage detection, generated ROI, deterministic rules, JSON and image evidence, and a CLI.
- **One-month target:** camera and barcode integration, product windows, local persistence, temporal aggregation, local dashboard, delayed upload, and initial central management.
- **Production target:** validated resilience, security, retention, observability, human review, release governance, and customer acceptance.
