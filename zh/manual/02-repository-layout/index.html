    02 — 存储库布局¶

    一个 monorepo 中的两个工作区：一个 Python uv 工作区（运行时 + 共享 包 + 培训）和 TypeScript pnpm 工作区（仪表板、桌面、 共享前端包）。

    顶级¶

    路径 内容
    pyproject.toml 根uv工作空间：成员apps/edge-service、packages/python/domain、packages/python/vision-core、training； Ruff/MyPy/Pytest 配置
    package.json、pnpm-workspace.yaml、pnpm-lock.yaml pnpm 工作区：apps/*、packages/typescript/*
    Makefile sync, lint, format, typecheck, test, web-install, web-check, check
    .github/workflows/ci.yml quality 工作（Python 门 + OpenAPI 漂移）+ web 工作（pnpm 构建/lint/测试 + TS 合约漂移 + Playwright e2e）
    .github/workflows/docs.yml 双语 MkDocs 构建 + GitHub Pages 部署
    config/examples/ pipeline.yaml、pipeline.cameras.yaml、product-rule.yaml
    models/manifests/ 占位符产品/组件清单（权重位于 Git 之外）
    tests/fixtures/ 用于快速 CI 的小型合成非敏感夹具
    docs/ 设计、决策 (ADR)、合同、操作手册、研究、审查、任务、本手册

    Python 工作区¶

    apps/edge-service — 包 assemblyvision_edge （控制台脚本 assemblyvision）¶

    检查运行时+本地API。下的一切 apps/edge-service/src/assemblyvision_edge/：

    模块 目的
    cli.py inspect、verify、serve、backup、restore 子命令
    config.py Pipeline/rule/edge config loading + all validation gates;持久规则身份注册
    pipeline.py InspectionPipeline：图像→记录流、出处检查、失败关闭决策合并
    camera_manager.py CameraSourceManager: one capture thread per instance, bounded queue, overflow tracking
    verify.py 保留验证评分+报告格式
    backup.py backup_edge / restore_edge（校验和 tar.gz 包）
    healthcheck.py python -m assemblyvision_edge.healthcheck <url> 容器活跃度
    barcode/ models, protocols (BarcodeDecoder), zxing (ZXing-cpp), keyboard (dev sim), resolver (exact-mapping)
    detection/ product_detector（第 1 阶段）、component_detector（第 2 阶段）、raw（Ultralytics 盒提取）、registry（ModelRegistry 共享权重）
    api/ app (create_app), settings (Server/Upload/Storage/Retention/IntegrityScan), state (EdgeRuntime/InstanceRuntime), deps (auth), events (RuntimeEventBus), problems (RFC 7807), logging_buffer, schemas
    api/routers/ auth、camera、configuration、derived、dev、device、health、inspection、inspections、logs、media、reviews、uploads、ws
    output/ writer.py：原子捆绑发布（inspection.json +媒体），注释渲染
    persistence/ schema (SQLAlchemy Core tables), repository (EdgeRepository), migrate (Alembic), reconcile (import/scan/quarantine)
    retention/ policy、storage（压力模式）、worker（RetentionCleanupWorker、O_NOFOLLOW 取消链接）
    rules/ rule_engine.py (RuleEngine.evaluate, rule_version_id)
    temporal/ aggregator (TemporalAggregator)、window_manager (ProductWindowManager)
    trigger/ source（TriggerSource、MockTriggerSource、IdentityCorrelator）、modbus_tcp（选择加入合同）
    upload/ scheduler（UploadScheduler、Http/目录接收器、令牌桶、断路器）

    另外：migrations/（Alembic），openapi/edge-openapi.json（承诺， 漂移检查）、Dockerfile、compose.yaml、pyproject.toml、 tests/（约 50 个测试文件）。

    packages/python/domain — package assemblyvision_domain¶

    规范 Pydantic 模型、错误、原因代码。唯一的依赖：pydantic。

    • models.py — APIModel 基础（extra="forbid"、from_attributes=True）； 枚举 InternalDecision、BusinessResult、InspectionLifecycle、 MediaLifecycle、ReviewDisposition、ComponentCorrectionState；型号 BoundingBox、Detection、FrameQuality、FrameQualitySummary、 BarcodeResult、ProductResolution、MediaMetadata、ProductDetection、 ROIResult、ComponentDetection、AggregatedComponentEvidence、 InspectionDecision，InferenceSettings/StageMetadata/Metadata， InspectionRecord、UploadTask、Artifact、DatasetReference、 ModelMetric、ModelManifest、ComponentCorrection、ReviewRecord； 助手allowed_review_dispositions(...)。
    • errors.py — AssemblyVisionError 基础； ConfigError、ImageReadError、 DetectionError（带有.reason_code），ROIGenerationError， RuleEvaluationError、OutputError。
    • reason_codes.py — the enforceable canonical reason-code set.

    packages/python/vision-core — 包 assemblyvision_vision¶

    ROI 引擎、帧源、清单加载。可选附加 video、rtsp、 http, gige keep it lean for central/lightweight consumers.

    • roi/roi_engine.py — ROIConfig, ROIEngine.generate (expand→clip→reject→crop).
    • roi/geometry.py — pure Box/Transform helpers (expand, clip, retained_fraction、translation_transform、inverse_transform、 apply_transform）。
    • sources/ — FrameSource协议+CapturedFrame； FolderSource， VideoFrameSource、OpenCVCameraSource、RTSPFrameSource、 HttpImageSource、GigEVisionFrameSource；惰性后端 (_opencv, _av、_harvester、_pacing)； factory.py (build_frame_source, FrameSourceConfig）。
    • manifests.py — load_model_manifest，verify_manifest_artifact （相对 URI + 大小 + SHA-256），verify_model_class_map， model_version_label、sha256_file。

    training — 包 assemblyvision-training （控制台脚本 av-train）¶

    Developer-only; 从未由运行时导入。 Subcommands product, prepare-components, component.模块：cli.py、dataset.py （验证），prepare_components.py（ROI 数据集生成）， train.py (Ultralytics wrapper), artifact.py (immutable weights/manifests/ 运行元数据）。基本权重缓存在 training/.cache/weights/ 中。

    TypeScript 工作区¶

    套餐 目的
    packages/typescript/api-client (@assemblyvision/api-client) ApiClient接口，MockApiClient，HttpApiClient，validate.ts，websocket.ts，types.ts，生成src/edge/generated/api.ts
    packages/typescript/ui (@assemblyvision/ui) DetectionViewer、StatusBadge、status.ts、geometry.ts、formatters/format.ts
    packages/typescript/eslint-config 共享平面 ESLint 配置
    apps/edge-web Vue 3 + Vite 仪表板； src/{pages,components,composables,stores,services,router}; tests/（维斯特）+ tests/e2e/（剧作家）
    apps/edge-desktop Electron shell (context isolation, sandbox, kiosk);加载构建的边缘网络输出

    adapt-roboflow-dataset.py / adapt-xanylabeling.py Real export → two-stage layout, strict validation, atomic publish
    e2e-demo.sh Full train→prepare→train→inspect→verify smoke with hard FN gate
    generate-edge-openapi.py Regenerate committed edge OpenAPI (CI drift check)
    translate-docs.py、generate-mkdocs-configs.py、build-docs.sh 双语文档构建
    edge-acceptance-run.py E6本地验收亚军（0/1/2出口）
    tests/ Pytest for adapters/generator/acceptance runner
